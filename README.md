# EEG Source Connectivity Analysis

Portfolio documentation for an academic MATLAB project that reconstructs cortical EEG sources, parcellates them into atlas-defined regions, and estimates directed connectivity.

For a fuller description of the project, see the [project overview](https://ilalunghini.github.io/projects/eeg-source-connectivity-analysis.html).

Read the [methodological pipeline](METHODOLOGY.md) for the complete sequence of analysis steps and selected MATLAB examples.

## Project context

This project was carried out as part of the course *Analisi e Modellazione dei Sistemi Biologici*. 
## Availability

No EEG recordings, MRI or atlas resources, cortical surfaces, derived outputs, figures, or complete analysis code are included because they may contain sensitive data. The methodology contains selected illustrative code excerpts.
